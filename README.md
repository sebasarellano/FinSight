# FinSight

Aplicación web local para gestionar y analizar las finanzas personales.

## Objetivo

FinSight es un proyecto de aprendizaje y desarrollo orientado a construir una herramienta que permita organizar ingresos, gastos, cuentas y presupuestos, con una interfaz moderna y visualizaciones financieras.

Además de desarrollar la aplicación, este proyecto busca practicar buenas prácticas de programación y aprender Git y GitHub mediante un flujo de trabajo progresivo.

## Funcionalidades previstas

- Dashboard con indicadores financieros y gráficos.
- Registro y gestión de ingresos y gastos.
- Administración de múltiples cuentas.
- Presupuestos mensuales por categoría.
- Filtros y búsqueda de transacciones.
- Exportación de datos a CSV.

*Estas funcionalidades están previstas y se implementarán progresivamente.*

## Tecnologías previstas

- Python y Flask
- HTML, CSS y JavaScript
- SQLite
- Chart.js
- Git y GitHub
- pytest para pruebas
